# bezstressoff.ru

Сайт-визитка психологического пространства Марины Сидоровой. Next.js (App Router, TypeScript), без CMS — весь контент прямо в коде страниц.

## Разработка

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # прод-сборка
npm run start   # запустить собранный прод-билд локально
npm run lint    # проверка ESLint
```

## Структура

- `src/app/` — страницы (App Router): `/`, `/services`, `/concept`, `/info`
- `src/components/` — переиспользуемые компоненты (шапка, футер, модалка записи, форма, карточки)
- `src/app/globals.css` — вся дизайн-система (цвета, типографика, компоненты) одним файлом
- `public/assets/` — фотографии и фоновая картинка

## Форма записи

Форма (модалка + блок «Контакты» на главной) отправляет `POST` на `/form.php`. Это унаследовано от прежней статической версии сайта — сам файл `form.php` не часть этого репозитория, он должен быть развёрнут на хостинге отдельно (PHP-скрипт, принимающий `name`/`phone`/`email`/`message` и отправляющий уведомление).

**Важно:** при деплое на Vercel (или любой чисто Node-хостинг) PHP не выполняется — форма перестанет работать, пока `/form.php` не будет либо продублирован на хостинге, либо заменён на Next.js API-роут (`src/app/api/contact/route.ts`) с реальной отправкой письма/уведомления.

## Instagram-посты

Раздел «Полезная информация» → «Статьи» показывает несколько постов из instagram.com/psybreakfast через официальный embed Meta (`src/components/InstagramFeed.tsx`). Чтобы добавить новый пост: скопировать его ссылку в массив `POSTS` в этом файле.
